# Volatile Compound Exploration

This dataset records a human-led search for chemical compounds that combine relatively high molecular weight with high volatility. Compiled around 2016, it contains more than 300 entries collected during an exploratory research project.

Each row may include a compound's name, molecular formula, molecular weight, boiling point, data source, and notes. 

The spreadsheet represents a typical manual scientific discovery from the pre-AI days, with its uneven coverage and organization structure, and as such may be useful for training models of human-lead data collection, analysis, and/or heavy volatile chemical compounds.

Please consult the cited sources and independently verify values before seriously relying on them.
